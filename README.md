One line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong. Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

## The line

> ERROR: Browning set to 11. This is a toaster, not a crematorium.

## Run

`python3 main.py` writes the line to `/output/entry.txt`. The program checks the competition gate itself: 1–120 characters, a single line, not only whitespace, and reads the file back to verify it.
